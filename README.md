# SIG LIST

제목·별칭과 단가로 시그니처를 검색하는 정적 웹페이지입니다. 별도 설치나 빌드가 필요하지 않습니다.

## 실행

폴더를 정적 웹서버로 실행해 주세요. 파일을 직접 여는 `file://` 방식에서는 데이터 요청이 제한될 수 있습니다.

```sh
/Users/air/.pyenv/versions/myenv312/bin/python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속해 주세요.

## 배포

- GitHub Pages: 파일을 저장소에 올린 후 Settings → Pages → Deploy from a branch에서 해당 브랜치와 `/ (root)`를 선택해 주세요.
- Cloudflare Pages: 정적 파일 직접 업로드 또는 Git 저장소 연결을 사용해 주세요. 프레임워크는 없음, 빌드 명령은 비워 두고 출력 폴더는 `.`으로 지정해 주세요.

`index.html`, `style.css`, `app.js`, `signatures.json`, `Jua-Regular.ttf`을 같은 폴더에 배포해 주세요. 하위 경로로 배포하는 GitHub Pages에서도 상대 주소로 동작합니다.

## 데이터와 검색

- 데이터는 같은 폴더의 `signatures.json`에서만 읽습니다. ymss API를 직접 호출하지 않습니다.
- 제목·별칭 검색은 부분 일치이며 공백과 영문 대소문자를 무시합니다.
- 검색창 하나에서 제목·별칭과 단가를 함께 검색합니다. 단가도 부분 일치로 검색하며 `15,000`과 `15000`을 동일하게 처리합니다.
- 어두운 배경의 반응형 이미지 목록으로 표시합니다. 전체·신규·단가 범위 버튼은 한 번에 하나만 선택됩니다. 신규를 선택하면 단가 범위가 해제되고, 단가 범위를 선택하면 신규가 해제됩니다. 선택된 단가 범위를 다시 누르면 전체로 돌아갑니다.
- 이미지 하단 40%에 가벼운 배경 블러를 적용하고, 빨간 글씨·흰 테두리·바깥 검정 테두리로 보정된 단가를 표시합니다. 원본 이미지 파일은 수정하지 않습니다. 원본 숫자는 블러 뒤로 비칠 수 있습니다.
- 단가 낮은 순으로 표시합니다. 가격 구간은 하한 포함, 상한 미포함입니다.
- 목록을 갱신하려면 프로젝트 폴더에서 `/Users/air/.pyenv/versions/myenv312/bin/python3 update_signatures.py`를 실행한 뒤, 바뀐 `signatures.json`을 GitHub에 올려 주세요. 2026-10-26 현재 원본 API와 359개 항목이 같습니다.
- 단가는 원본의 10분의 1로 표시합니다. 드라군만 예외적으로 25,500으로 표시하며 10으로 나누지 않습니다. 검색과 정렬에도 표시 단가를 사용합니다.

이미지는 원본 이미지 서버에서 불러옵니다.
